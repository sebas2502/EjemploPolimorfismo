# Ejemplo de Polimorfismo en Java

Ejemplo utilizado para explicar polimorfismo en Programación Orientada a Objetos.

## Conceptos

- Herencia
- Clases abstractas
- Sobrescritura de métodos
- Polimorfismo

## Ejemplo

El sistema representa diferentes medios de notificación:

- Email
- WhatsApp
- SMS

Todos implementan el método `enviar()`, pero cada clase proporciona su propia implementación.
